## 🛠️ Setting Up Your Environment

### 1. Check if Python is Installed
Open the terminal in Cursor (Terminal → New Terminal) and run:
```bash
python3 --version
```
If Python isn't installed, you can install it from [python.org](https://python.org).

### 2. Your First Python Program
Let's test your setup by running the first lesson:

```bash
# Navigate to the lessons directory
cd lessons/week01-fundamentals

# Run your first Python program
python3 lesson01_setup_and_hello_world.py
```

## 🚨 Common Beginner Issues

### Python Version
- Use `python3` instead of `python` on most systems
- Make sure you're using Python 3.8 or newer

### Indentation Errors
- Python uses indentation to define code blocks
- Use 4 spaces (not tabs) for indentation
- Be consistent with your indentation

### File Paths
- Make sure you're in the right directory when running files
- Use `pwd` to check your current directory
- Use `ls` or `dir` to see available files
